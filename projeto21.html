O que é

Um método simples para dar o primeiro passo

O Projeto 21 é um desafio de 21 dias criado para ajudar você a dar o primeiro passo em direção a uma rotina mais saudável. O material reúne:

01

Alimentação

Dicas práticas para uma alimentação mais equilibrada no dia a dia.

02

Movimento

Exercícios e sugestões de atividade física para todos os níveis.

03

Hidratação

Como manter uma boa hidratação de forma consciente.

04

Sono e recuperação

Hábitos para dormir melhor e recuperar o corpo.

05

Acompanhamento diário

Um jeito simples de registrar sua evolução dia após dia.

06

Desafios simples

Pequenas metas para cada etapa do desafio.

Como funciona

21 dias, divididos em 3 etapas

Cada etapa constrói a base para a próxima — sem pressa, sem exageros.

1–7

Começando a mudança

Os primeiros ajustes na rotina, sem pressão — só o essencial para dar o pontapé inicial.

8–14

Criando consistência

Os hábitos começam a se firmar. É hora de manter o ritmo e observar o progresso.

15–21

Consolidando hábitos

A rotina começa a fazer parte do seu dia — o novo padrão vira natural.

Não é sobre fazer tudo perfeito.
É sobre criar constância.

O Projeto 21 foi pensado para pequenas mudanças diárias — sem promessas milagrosas, sem dietas extremas. Só passos pequenos, repetidos por 21 dias.
